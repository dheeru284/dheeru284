# ▶ Claude YouTube — Faceless Channel Manager (free)

All 14 commands, zero cost, no API keys, no install.

## Use it
- **Web:** open `index.html` in a browser (works offline; markdown rendering loads from CDN if online).
- **CLI:** `node cli.js "/ideas productivity 20"` or `node cli.js` for interactive mode.
- **Full AI mode:** paste `SYSTEM_PROMPT.md` into any free AI chat.

## Commands
`/channel-audit` `/ideas` `/hook` `/script` `/title` `/thumbnail` `/seo` `/shorts` `/weekly-plan` `/trends` `/thumbnail-text` `/cta` `/comment-reply` `/upload-checklist`

Two-part args use `|`: `/seo deep work | deep work, focus tips`. Script length is the last word: `60s`, `3min`, `8min`, `10min`.
